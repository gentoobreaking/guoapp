本项目 fork 自 [Xanerix/guoapp](https://github.com/Xanerix/guoapp)，上游改编自 [fish2018](https://github.com/fish2018) 的源码。安装包内置红果站源，其余站源以模块形式在应用内的**模块**商店安装。

> [!WARNING]
> 项目处于开发阶段，不对用户数据做担保，数据可能在版本更新时丢失。

## 本 fork 的改动

相对上游（应用版本 2.0.1，2026 年 11 月）的差异：

- **电视下载闭环**——上游不提供电视端下载。本 fork 在电视上补齐完整下载流程：「我的」页下载入口、下载队列与已下载页采用电视过扫描安全边距的布局，批量与范围选集对话框支持 D-pad 操作。
- **多集预载**——除了提前缓冲下一集，「预载为完整下载」模式会按观看顺序把后续集数整集下载到磁盘（可预载 1–5 集），弱网或离线也能连续观看。排程幂等去重，并按下载偏好跳过 VIP 集。
- **资源参数可调**——管理员可设置 HLS 分片下载数（1–8）、预取大小（4/8/16 MB）与目录请求并发数（1–6），由 Go 核心持久化，实际作用于下载、预取与目录请求。
- **音频焦点（Android）**——播放器正确申请音频焦点，短暂失去焦点（含 duck 请求）即暂停；只有因焦点而暂停的播放会自动恢复；离开播放页归还焦点。画中画与音频焦点共用同一个原生回调分发器。
- **切集更快**——预载计划信任站源声明的凭证有效期（上限 10 分钟），不再被提前作废；解析播放地址有 25 秒看门狗，卡住自动取消重试；加载超过 12 秒显示「重新获取」按钮。
- **画质筛选**——清晰度菜单只列出 720P 及以上（「自动」仍会回退到低画质）；「发现」列表提供 全部画质 / 720P+ / 1080P 筛选，基于本地观测到的每部剧画质（播放时记录；打开详情页时会在后台解析第一集补齐记录）。
- 其他：Gradle wrapper 改用 `-bin` 发行包，Android Gradle Plugin 9.1.1。

目录 API 不提供视频画质信息，列表筛选因此基于这些本地观测记录——筛选开启时，还没播放或打开过详情的剧会被隐藏。

## 功能

### 界面与外观

- **导航**：发现 / 追剧 / 我的。手机用底栏，平板和电脑用侧栏（可收起），电视用顶部 Tab；宽屏的子页面在侧栏右侧打开。
- **界面模式**：自动识别、电视、手机、平板、窗口（只有电脑提供）；手动选定后不随窗口宽度切换。电视模式强制横屏，手机模式锁定竖屏。
- **主题**：跟随系统取色（Android 12+ 跟随壁纸，Windows 和 macOS 跟随强调色）或 6 个预设色板；浅色 / 深色 / 跟随系统。

### 浏览

- **发现**：站源名旁切换站源；分类 Tab 依次为推荐 / 全部 / 各榜单 / 各题材，榜单封面标出名次。第一个 Tab 顶部大卡片显示最近看过或推荐的剧。滑到底自动加载，下拉或「刷新」重新拉取当前分类。另有画质筛选（全部画质 / 720P+ / 1080P，本 fork 新增），只列出已知高画质片源的剧。
- **搜索**：只搜当前站源，保留最近搜索；红果有输入联想。
- **详情**：封面模糊作底，显示集数、完结状态、分类、播放量、标签和简介；选集每组 30 集，落在续播那一集，看过的集变浅，VIP 集有标记。打开时后台预缓冲续播集；打开详情页也会顺带记录该剧的片源画质，供列表筛选使用。

### 播放

| 设备 | 体验 |
| --- | --- |
| 电脑 | 左边视频、右边选集栏，可宽屏、全屏；悬停弹出清晰度、倍速、音量；支持空格、Enter、方向键、Page Up / Page Down、M 等快捷键 |
| 手机 | 竖屏短剧沉浸式，上下翻页切集，左右滑快进快退，长按画面打开「播放设置」，长按左右两侧倍速播放（默认 2 倍，可在设置里改），可锁定。横屏视频竖拿时视频在上、简介 / 选集在下，转横屏自动全屏；全屏双击两侧快退 / 快进，左半屏上下滑调亮度，右半屏调音量 |
| 平板 | 横着拿同电脑，竖着拿同手机，全屏期间锁定横屏 |
| 电视 | 播控浮在画面上，隐藏时左右键快退 / 快进 10 秒；返回键依次关闭选项、收起播控、退出；换集回详情页选 |

所有设备通用：下一集提前缓冲，翻页和连播直接接上；倍速、清晰度和弹幕开关会记住。红果在线播放有弹幕，本地播放不加载。Android 上播放器会配合其他音频应用正确处理音频焦点（本 fork 新增）。

### 追剧与记录

- **追剧**：只分追 / 不追。有新集的剧排在「有更新」并标出更新集数；可搜索、按站源筛选、多选取消。后台每 30 分钟检查一批未完结的追剧。
- **观看记录**：按今天 / 昨天 / 更早分段；可搜索、按站源筛选、多选删除，「清空」只清当前列出的记录。
- **我的**：用户卡、最近观看、下载概况和设置入口；底栏 / 侧栏图标显示正在下载的集数。内含下载入口，可打开下载队列与已下载片库。

### 下载

- 详情页「下载选集」或播放页选集栏多选（点选、拖选、全选）。
- 下载页分「下载中」「已下载」，可单集或全部暂停 / 继续 / 重试；已下载按剧显示，可播放、删除、补齐缺集。所有设备形态**包括电视**都可用（本 fork 新增）。
- 每集下载完自动转成普通 mp4（红果先解密，m3u8 合成一个文件），保存为 `下载目录/剧名/第 N 集.mp4`，可以直接拷出使用。
- 旧版下载的分集保持原样，旧版合并出的文件不再列出。

### 设置、用户与备份

- **设置**：外观、播放、弹幕、下载、存储、代理、用户、关于、诊断 9 组，改动立即保存；没有权限的项置灰并注明原因。
- **用户**：多用户独立保存追剧、记录和搜索，轻点即切换；管理员可添加、编辑、删除用户，设置能访问的站源和是否允许下载。
- **备份**：导出 / 恢复用户、追剧、观看记录和偏好设置（含主题色），已下载视频不受影响；旧版备份仍可导入。本地配置损坏时启动页可从备份恢复。

## 安装

本 fork 目前的安装包以源码自行构建为主——见 [Releases](https://github.com/gentoobreaking/guoapp/releases) 页面；上游项目的现成安装包在上游 [Releases](https://github.com/Xanerix/guoapp/releases)。`[NEEDS VERIFICATION：本 fork 何时/是否发布自己的安装包]`

从源码构建 Android 版：

```sh
python3 scripts/build_native.py --platform android --abi arm64-v8a   # 或 armeabi-v7a / x86_64
python3 scripts/build_android.py                                     # 三种架构一次出齐
```

其他平台、模块内置方式（`--bundle`）与发布流程见 [DEVELOPMENT.md](DEVELOPMENT.md)。

| 平台 | 安装包 |
| --- | --- |
| Android 7.0+ | arm64-v8a / armeabi-v7a / x86_64 三种 APK，按设备架构选择（大多数手机选 arm64-v8a；不少电视是 armeabi-v7a）；同一签名可覆盖升级 |
| Windows 10/11 x64 | 安装包 `*-setup.exe`（装到当前用户、免管理员权限）或便携 ZIP；便携版的设置、记录与下载存在程序旁的 `userdata` 目录 |
| iOS 15.1+ | 未签名 IPA，需自行签名或用 iloader 等工具侧载 |
| macOS 12+ | 通用 dmg（Apple 芯片与 Intel），未公证——首次打开前需解除隔离 |

> [!TIP]
> Android 提示 `INSTALL_FAILED_NO_MATCHING_ABIS` 表示 APK 与设备架构不匹配，请换对应架构的安装包。

> [!IMPORTANT]
> macOS 首次打开前在终端执行：
>
> ```sh
> xattr -dr com.apple.quarantine /Applications/影片庫.app
> ```

## 检查更新与使用统计

| 请求 | 发送内容 |
| --- | --- |
| 检查更新 | 不发送任何数据，只读取最新版本号。启动时检查一次，有新版时每次启动都会提示，可选择忽略此版本或不再提醒 |
| 匿名使用统计 | 只发送：首次统计时生成的随机编号（与设备、账号无关）、应用版本号、平台（Android / iOS / Windows / macOS）、构建标识（固定为 `guoapp`） |

不发送观看记录、追剧、搜索、站源设置或其他任何个人数据，接收端代码见 [`worker/`](worker)。两项都可以在 **设置 › 关于** 分别关闭。统计端点网址在构建期注入（`UPDATE_SERVER_URL`）；未设置时（例如未配置此变量的本地与 fork 构建），应用完全不会发出对应请求。
